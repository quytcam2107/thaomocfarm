## 1. HẠ TẦNG BẮT BUỘC (1 VPS DUY NHẤT, CẤM DỊCH VỤ NGOÀI)
- MONO PROJECT: web khách + admin trong 1 ứng dụng Laravel. Admin dùng route prefix `/admin` + middleware + policy.
- DB: MySQL 8/MariaDB cài trên server (không read replica).
- Cache: driver **file**. KHÔNG Redis => CẤM `Cache::tags()`. Bắt buộc dùng cache key kèm version qua helper `remember_group()` và `bump_group_version()`.
- Queue: driver **database**, worker chạy bằng supervisor.
- Session: driver **database**.
- File/ảnh: disk `public` + `php artisan storage:link`, Nginx serve cùng server.
- Tìm kiếm: MySQL **FULLTEXT** index, fallback **LIKE**. Không Meilisearch/Algolia.
- Frontend: **Blade + Tailwind** build local bằng **Vite + Alpine.js/vanilla JS**. Components dùng CSS class tự đặt kiểu BEM, **chỉ dùng anonymous component** (file .blade.php trong `resources/views/components/`, khai báo `@props`), KHÔNG dùng class-based component.
- **CSS**: tách thành 12 partial files trong `public/assets/css/partials/01-base.css` → `12-layout-extras.css`. File entry `public/assets/css/style.css` CHỈ chứa các dòng `@import url('partials/XX-name.css');`. KHÔNG dùng command build. Font import nằm TRONG `01-base.css` qua `@import url('../fonts.css');`.
- Không Octane, không Docker.
- Deploy: `git pull` + `composer install --no-dev` + `php artisan optimize` + `migrate --force`.

## 2. QUY TẮC CODE BẮT BUỘC
- PHP >= 8.3, mọi file PHP bắt đầu bằng `declare(strict_types=1);`
- Model chuẩn Laravel 13: attribute `#[UseFactory(XFactory::class)]`, `#[Hidden([...])]`; `protected $fillable` dạng list; method `casts()`; docblock generics cho quan hệ: `@return HasMany<Product, $this>`.
- Controller mỏng -> gọi Service (`app/Services`); Service trả **array/DTO**.
- Docblock tiếng Việt ngắn gọn cho mọi method public.
- **Eager loading + select cột cần dùng**; TUYỆT ĐỐI không N+1 ở home và list.
- **TIỀN TỆ**: lưu **INTEGER UNSIGNED VND** (199000 = 199.000đ). Hiển thị: helper `format_vnd()` hoặc `number_format($x) . '₫'`.
- **KHÔNG foreign key constraint** ở tầng DB: mọi khóa ngoại là `unsignedBigInteger + index`; quan hệ Eloquent chỉ là app-level; Service layer chịu trách nhiệm toàn vẹn dữ liệu.
- **Counters denormalize** trên `products` (`price_min`, `stock_total`, `sold_count`, `rating_avg`, `rating_count`): cập nhật bằng `increment()` hoặc job queue.
- **Chốt slot flash sale & trừ tồn kho** bằng conditional UPDATE nguyên tử trong `DB::transaction`:
  + `whereColumn('qty_sold','<','qty_total')` rồi `update qty_sold+1`
  + `where('stock','>=',$qty)` rồi `update stock-$qty`
  + affected rows = 0 => throw exception + rollback. **CẤM select-check-update**.
- Đơn hủy / COD quá hạn: job schedule nhả tồn + hoàn slot deal + ghi `stock_movements`.
- Cache từng block trang chủ với TTL riêng qua `remember_group()`.
- Countdown flash sale: server chỉ trả `end_at` (ISO 8601), JS client tự đếm giây.
- Upload ảnh: validate mime/size, lưu disk public, job queue sinh thumbnail 300/600/1200 (WebP hoặc JPG) bằng Intervention Image chạy GD.
- Tìm kiếm: FULLTEXT(name) fallback LIKE; log `search_terms` qua queue; gợi ý tìm kiếm từ top terms.
- Bảo mật: FormRequest cho mọi input; Policy cho admin; rate limit login/checkout/apply coupon; escape Blade mặc định; slug unique tự sinh; `order_number` dạng `TMX-yyyyMMdd-xxxxx`.

## 3. BẪY & BÀI HỌC (BẮT BUỘC TRÁNH)
1. **Closure constraint trong `with()`** nhận **RELATION** (BelongsTo/HasOne/HasMany...), KHÔNG phải Builder. => hint `Illuminate\Database\Eloquent\Relations\Relation`, return `void`. Chỉ `withCount()` và `whereHas()` mới nhận Builder.
2. **`select()` trong closure eager load** của `relation->ofMany()` PHẢI định danh tên bảng, ví dụ `'product_images.product_id'`, vì eager load `ofMany` dùng INNER JOIN derived table => không định danh sẽ lỗi MySQL 1052 ambiguous.
3. **Cache driver file** dùng `serialize/unserialize`: **CẤM đưa object (stdClass lẫn DTO) vào giá trị cache**. **CHUẨN**: closure của `remember_group()` chỉ trả **array/scalar thuần**; hydrate DTO **SAU** khi đọc cache về.
4. **Sau khi thêm/đổi route** phải chạy `route:clear` (đã gặp lỗi "Route [web.cart.add] not defined").
5. **Sau khi đổi dữ liệu hiển thị** phải bump cache nhóm: `php artisan thaomoc:bump-cache {home|catalog|review}`.
6. **Quy ước đường dẫn ảnh** ĐANG TỒN TẠI: icon danh mục: `asset('assets/images/categories/' . $icon)`, fallback `asset('assets/images/category-default.svg')`. Ảnh flash sale: `asset('assets/images/' . $path)`, fallback `asset('images/product-default.svg')`. Gallery PDP: component tự `asset($path)`, fallback `'images/placeholder.svg'`. Card danh mục: `asset('storage/' . ltrim($path, '/'))`, fallback `asset('images/product-default.svg')`.
7. **Chuỗi thương hiệu** trong blade hiện tại là **"Mộc Xanh"** (title, schema JSON-LD); tên dự án/prefix đơn hàng là **TMX / "Mộc Xanh"**. KHÔNG tự đổi tên thương hiệu.
8. **Biến view** của block flash sale trên home tên là `$flashProducts` (không phải `$flashSale`).
9. **PHP 8.1+ ném TypeError** khi `trim(null)` trong Blade `@if (!empty($x)) ... trim($x) ... @endif` – vì Blade compile cả khối `@if` trước khi check `!empty()`. **CHUẨN**: cast `(string)` trước `trim()` hoặc gán biến mặc định `$desc = (string) ($x ?? '');` rồi dùng `$desc`.
10. **Route catch-all `/{slug}`** PHẢI đặt **cuối cùng** trong `routes/web.php`, sau mọi route có prefix (`/san-pham/*`, `/gio-hang/*`, `/tra-cuu-don`...). Phải ràng buộc `->where('slug', '[a-z0-9\-]+')` để không nuốt file tĩnh (`.ico`, `.xml`) hay URL có dấu `.`.
11. **Anonymous Blade Component** dùng `@props([...])`, KHÔNG dùng `$this`, KHÔNG truyền Closure vào `:prop`, KHÔNG lồng `<main>` trong view con vì `x-layouts.app` đã bọc `<main id="main">`. View con chỉ cần `<div class="container">`.
12. **Truyền dữ liệu cho Blade component**: chỉ truyền scalar/array thuần, không truyền Closure/Paginator object; với `Paginator` dùng `$paginator->toArray()` hoặc tự map ra `['total', 'current_page', 'last_page', 'from', 'to', 'per_page']`.
13. **JS `input.value = code` không fire event**: khi gán value bằng JS, trình duyệt KHÔNG tự fire `input`/`change`. **BẮT BUỘC** `input.dispatchEvent(new Event('input', { bubbles: true }));` sau khi gán để handler lắng nghe biết value đã đổi (đã áp dụng cho syncApplyButton ở giỏ hàng).
14. **ALTER TABLE trực tiếp vs migration**: khi schema đã có dữ liệu và không muốn chạy `migrate` (sợ mất data), chạy SQL ALTER trực tiếp trên MySQL (ví dụ `ALTER TABLE orders ADD COLUMN coupon_code_snapshot VARCHAR(50) NULL AFTER coupon_id;`) rồi tạo file migration chỉ để đồng bộ schema cho sau này. Migration dùng `Schema::hasColumn()` check trước khi thêm/xóa để an toàn.
15. **Component Blade tự ẩn khi không có dữ liệu**: wrap toàn bộ component trong `@if(is_array($data) && count($data) > 0)` thay vì render fallback cứng. View cha truyền `$data ?? null` — nếu DB không có bản ghi active thì section tự biến mất, không còn khoảng trống vô nghĩa (đã áp dụng cho `<x-sections.coupons>`).
16. **Layout component có thể nhận prop để ẩn component con**: pattern `hideCatnav` / `hideFloatnav` truyền từ view vào `<x-layouts.app :hide-floatnav="true">`, layout truyền xuống component con `<x-floatnav :hide-floatnav="$hideFloatnav" />`, component con bọc nội dung trong `@if(!($hideFloatnav ?? false))`. Consistent với `<x-header>`.

Trả array{items, subtotal, discounted_subtotal, shipping_fee, shipping_method, discount, appliedCoupon, total, free_shipping_threshold}.

- `processCheckout(int $cartId, array $validated)`: DB::transaction tạo Order + OrderItem + Shipment + StockMovement + coupon_usages. Conditional UPDATE trừ tồn kho. Ghi `coupon_code_snapshot`. Xóa cart_items + session coupon sau khi thành công.
- `generateOrderNumber()`: `TMX-yyyyMMdd-xxxxx` unique.
