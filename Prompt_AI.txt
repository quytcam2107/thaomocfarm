## 1. HẠ TẦNG BẮT BUỘC (1 VPS DUY NHẤT, CẤM DỊCH VỤ NGOÀI)
- MONO PROJECT: web khách + admin trong 1 ứng dụng Laravel. Admin dùng route prefix `/admin` + middleware + policy.
- DB: MySQL 8/MariaDB cài trên server (không read replica).
- Cache: driver **file**. KHÔNG Redis => CẤM `Cache::tags()`. Bắt buộc dùng cache key kèm version qua helper `remember_group()` và `bump_group_version()`.
- Queue: driver **database**, worker chạy bằng supervisor.
- Session: driver **database**.
- File/ảnh: disk `public` + `php artisan storage:link`, Nginx serve cùng server.
- Tìm kiếm: MySQL **FULLTEXT** index, fallback **LIKE**. Không Meilisearch/Algolia.
- Frontend: **Blade + Tailwind** build local bằng **Vite + Alpine.js/vanilla JS**. Components dùng CSS class tự đặt kiểu BEM.
- Không Octane, không Docker.
- Deploy: `git pull` + `composer install --no-dev` + `php artisan optimize` + `migrate --force`.

## 2. QUY TẮC CODE BẮT BUỘC
- PHP >= 8.3, mọi file PHP bắt đầu bằng `declare(strict_types=1);`
- Model chuẩn Laravel 13: attribute `#[UseFactory(XFactory::class)]`, `#[Hidden([...])]`; `protected $fillable` dạng list; method `casts()`; docblock generics cho quan hệ: `@return HasMany<Product, $this>`.
- Controller mỏng -> gọi Service (`app/Services`); Service trả **array/DTO**.
- Docblock tiếng Việt ngắn gọn cho mọi method public.
- **Eager loading + select cột cần dùng**; TUYỆT ĐỐI không N+1 ở home và list.
- **TIỀN TỆ**: lưu **INTEGER UNSIGNED VND** (199000 = 199.000đ). Hiển thị: helper `format_vnd()` hoặc `number_format($x) . '₫'`.
- **KHÔNG foreign key constraint** ở tầng DB: mọi khóa ngoại là `unsignedBigInteger + index`; quan hệ Eloquent chỉ là app-level; Service layer chịu trách nhiệm toàn vẹn dữ liệu.
- **Counters denormalize** trên `products` (`price_min`, `stock_total`, `sold_count`, `rating_avg`, `rating_count`): cập nhật bằng `increment()` hoặc job queue.
- **Chốt slot flash sale & trừ tồn kho** bằng conditional UPDATE nguyên tử trong `DB::transaction`:
  + `whereColumn('qty_sold','<','qty_total')` rồi `update qty_sold+1`
  + `where('stock','>=',$qty)` rồi `update stock-$qty`
  + affected rows = 0 => throw exception + rollback. **CẤM select-check-update**.
- Đơn hủy / COD quá hạn: job schedule nhả tồn + hoàn slot deal + ghi `stock_movements`.
- Cache từng block trang chủ với TTL riêng qua `remember_group()`.
- Countdown flash sale: server chỉ trả `end_at` (ISO 8601), JS client tự đếm giây.
- Upload ảnh: validate mime/size, lưu disk public, job queue sinh thumbnail 300/600/1200 (WebP hoặc JPG) bằng Intervention Image chạy GD.
- Tìm kiếm: FULLTEXT(name) fallback LIKE; log `search_terms` qua queue; gợi ý tìm kiếm từ top terms.
- Bảo mật: FormRequest cho mọi input; Policy cho admin; rate limit login/checkout/apply coupon; escape Blade mặc định; slug unique tự sinh; `order_number` dạng `TMX-yyyyMMdd-xxxxx`.

## 3. BẪY & BÀI HỌC (BẮT BUỘC TRÁNH)
1. **Closure constraint trong `with()`** nhận **RELATION** (BelongsTo/HasOne/HasMany...), KHÔNG phải Builder. => hint `Illuminate\Database\Eloquent\Relations\Relation`, return `void`. Chỉ `withCount()` và `whereHas()` mới nhận Builder.
2. **`select()` trong closure eager load** của `relation->ofMany()` PHẢI định danh tên bảng, ví dụ `'product_images.product_id'`, vì eager load `ofMany` dùng INNER JOIN derived table => không định danh sẽ lỗi MySQL 1052 ambiguous.
3. **Cache driver file** dùng `serialize/unserialize`: **CẤM đưa object (stdClass lẫn DTO) vào giá trị cache**. **CHUẨN**: closure của `remember_group()` chỉ trả **array/scalar thuần**; hydrate DTO **SAU** khi đọc cache về.
4. **Sau khi thêm/đổi route** phải chạy `route:clear` (đã gặp lỗi "Route [web.cart.add] not defined").
5. **Sau khi đổi dữ liệu hiển thị** phải bump cache nhóm: `php artisan thaomoc:bump-cache {home|catalog|review}`.
6. **Quy ước đường dẫn ảnh** ĐANG TỒN TẠI: icon danh mục: `asset('assets/images/categories/' . $icon)`, fallback `asset('assets/images/category-default.svg')`. Ảnh flash sale: `asset('assets/images/' . $path)`, fallback `asset('images/product-default.svg')`. Gallery PDP: component tự `asset($path)`, fallback `'images/placeholder.svg'`.
7. **Chuỗi thương hiệu** trong blade hiện tại là **"Thảo Mộc Xanh"** (title, schema JSON-LD); tên dự án/prefix đơn hàng là **TMX / "Thảo Mộc Farm"**. KHÔNG tự đổi tên thương hiệu.
8. **Biến view** của block flash sale trên home tên là `$flashProducts` (không phải `$flashSale`).
