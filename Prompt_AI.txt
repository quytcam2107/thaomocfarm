# Bối cảnh
Dự án Laravel "Thảo Mộc Farm" (Blade + CSS/JS tĩnh trong public/assets, mobile-first).
Tài liệu ngữ cảnh đã có sẵn trong repo — BẮT BUỘC đọc 3 file sau TRƯỚC khi làm bất cứ gì:
- PROJECT_CONTEXT/README.md   → rule làm việc + quy ước kỹ thuật cốt lõi
- PROJECT_CONTEXT/01-DATABASE.md → schema thật của 34 bảng (cột, index, enum, unique)
- PROJECT_CONTEXT/02-CODE.md  → models/scopes/enums/services/controllers/routes/views/CSS partials/contract JS/config/helpers

# Quy tắc thực hiện (tóm tắt từ README.md — áp dụng đầy đủ theo README)
1. Đọc toàn bộ file liên quan trước khi sửa; đối chiếu tài liệu với code thật — code thật thắng, báo lại nếu lệch.
2. Bám sát tên route/cột/class/selector THẬT trong dự án, không bịa, không giả định. Giữ tương thích ngược các contract (#cartBadge, .add-cart, #toast, meta csrf-token, data-drawer-*). Route mới phải đặt TRƯỚC catch-all /{slug}. Không refactor ngoài phạm vi.
3. Xuất code: file nào sửa/tạo → MỘT code block chứa TOÀN BỘ nội dung file, phía trên ghi "### File: đường/dẫn/file". Không diff, không placeholder "...". Nội dung không liên quan giữ NGUYÊN VĂN bản gốc.
4. Đủ mắt xích: CSS ↔ Blade ↔ JS ↔ Route/Controller phải liệt kê hết file thay đổi. Comment tiếng Việt ngắn tại logic mới.
5. Kết thúc: tóm tắt file đã sửa + luồng hoạt động + điểm cần tôi kiểm tra trên trình duyệt/database.
